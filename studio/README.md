# Energy Icons Studio

The glossary. Icon masters stay in the git repo; this Studio holds the plain-English definitions the website reads.

```bash
npm run dev
```

Opens at http://localhost:3333. The website should be running at http://localhost:3000 so Presentation can preview `/glossary`.

The hosted Studio is [energy-icons.sanity.studio](https://energy-icons.sanity.studio/).

`npm run typegen` refreshes the website's query types after a schema or query change.
